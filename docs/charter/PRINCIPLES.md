# PRINCIPLES

1. Never invent domain knowledge to unblock implementation.
2. Never treat LLM cultural output as validated truth.
3. Preserve uncertainty and disagreement.
4. Separate interpretation, evidence, coverage, ontology adequacy, and validation status.
5. Preserve source text immutably.
6. All derived interpretations carry provenance.
7. Human validation is a distinct epistemic event.
8. Confirmed failures become regression cases.
9. Prefer explicit schemas over implicit agents.
10. Do not train models until architecture + retrieval evaluation fails.
